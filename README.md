
# 📖 StoryVerse
### AI-Based Interactive Storytelling Agent

StoryVerse is an interactive storytelling application developed using Python and Streamlit. It allows users to create stories, explore different genres, make choices and experience different story paths.

## ✨ Features

- 🎭 Multiple story genres:
  - Fantasy
  - Horror
  - Mystery
  - Adventure
- ✍️ Interactive story creation
- 🤔 User-based story choices
- 🧠 Character memory
- 📜 Story history
- 📥 Download stories as text files
- 🎨 User-friendly interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Random Module

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/chaithanya-shetty030/AI-Interactive-Storytelling.git
```

2. Open the project folder:

```bash
cd AI-Interactive-Storytelling
```

3. Install Streamlit:

```bash
pip install streamlit
```

4. Run the application:

```bash
python -m streamlit run app.py
```

## 🎯 Project Objectives

- To provide interactive storytelling.
- To allow users to explore multiple genres.
- To maintain character and story event information during a session.
- To provide story downloading functionality.
